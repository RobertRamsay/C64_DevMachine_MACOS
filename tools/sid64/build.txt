sid64 - reSID wrapper for C64 Dev Machine

Windows (already built: sid64.dll, x64, static runtime, no extra DLLs needed):
  x86_64-w64-mingw32-g++ -O3 -fpermissive -w -shared -static -static-libgcc -static-libstdc++ -o sid64.dll sid64.cpp resid/*.cpp resid-fp/*.cpp

macOS: run tools/sid64/build_mac.sh (needs Xcode command line tools: xcode-select --install).
It writes C64Devmachine/extensions/sid64/libsid64.dylib (universal arm64 + x86_64).
